# The generated knowledge index only carries a note's first heading

As of U-005, `docs/knowledge/README.md`'s `## Index` section is generated by `node tool/knowledge-index.mjs` from the files on disk, between `<!-- index:start -->` and `<!-- index:end -->`; it must not be hand-edited (`tool/gate.sh`'s `knowledge-index` stage fails on a stale index). The generator's description for each note is exactly that note's first line (`# ` heading) — none of the hand-written prose that used to follow a dash after the title in the old hand-maintained index survives.

Write the heading itself to say what a reader deciding whether to open the note needs to know (the specific rule or gotcha, not a generic title like "Notes on X"), because the heading is now the only text that reaches the index. If a note's old hand-written hook was load-bearing, fold it into the heading rather than relying on it living beside the link.

Source: U-005, 2026-09-09.
